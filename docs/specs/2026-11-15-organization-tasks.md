# 组织任务

2026-11-15. Issue [#36](https://github.com/aningdev/org-saas/issues/36).

## Why

平台壳（组织、成员、角色、团队、归档）已落地，但仍没有组织内可协作的业务资源；权限词表里的「修改任务」示例与「个人收藏」都悬空。组织成员需要一个最小、可授权的业务对象，用来验证组织工作空间里的读写与权限边界。

## Goal

活跃组织的成员能在组织工作空间内创建、查看、更新和完成**组织任务**；具备删除权限的成员可删除任务。归档组织不能进行任务业务。任务始终属于创建它的组织，且不跨组织可见。

## Out of scope

- 个人任务、个人收藏入口与收藏表
- 任务评论、附件、子任务、看板列、标签、到期提醒、指派人
- 计费、配额、按任务用量计量
- 小程序 / 独立 App 客户端
- 目标共享／生产库的 schema 应用（仍受 [#30](https://github.com/aningdev/org-saas/issues/30) 门禁）

## Acceptance criteria

- [ ] **组织成员**在活跃组织侧栏打开「任务」，**看到**本组织任务列表（可为空）。_(manual)_
  - Example: 成员进入 `/org/acme/tasks` → 标题「任务」与空状态或已有任务行
- [ ] **具有创建权限的成员**填写标题并提交，**看到**新任务出现在列表且状态为未完成。_(automated)_
  - Example: 标题「准备季度汇报」→ 列表出现该行，状态为进行中／未完成
- [ ] **具有更新权限的成员**将未完成任务标为完成，**看到**该任务显示为已完成。_(automated)_
  - Example: 点击「完成」→ 行状态变为已完成
- [ ] **仅具有读权限、无删除权限的成员**看不到可用的删除操作；**具有删除权限的成员**删除后，**看到**该任务从列表消失。_(manual)_
  - Example: 普通成员无删除按钮；管理员删除「过期草稿」→ 列表不再显示
- [ ] **非本组织成员**不能列出或改写该组织任务。_(automated)_
  - Example: 另一组织会话请求列表 → 拒绝／不可见
- [ ] **组织已归档**时，成员不能创建或更新任务；owner 走归档恢复路径，不进入任务业务页。_(manual)_
  - Example: 归档后访问任务业务 → 被导向归档页或写操作被拒绝

## Open questions

（无 — 首域定为组织任务；v1 仅标题 + 未完成／已完成；成员默认可创建／读／更新，管理员与所有者另可删除。）
